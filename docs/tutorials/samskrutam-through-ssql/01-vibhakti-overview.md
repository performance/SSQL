# अध्याय १: विभक्तिपरिचयः

## विभक्तिः किम्?

संस्कृतभाषायाम् **विभक्तिः** (Vibhakti) शब्दानाम् कार्यम् सूचयति।
SSQL भाषायाम् विभक्तयः SQL क्रियासु प्रयुज्यन्ते।

## सप्त विभक्तयः

| विभक्तिः | कार्यम् | SQL सम्बन्धः |
|---------|--------|-------------|
| **प्रथमा** | उक्तम् कारकम् (कर्मणि प्रयोगे कर्म) | SELECT columns |
| **द्वितीया** | कर्म | Direct objects |
| **तृतीया** | करणम् | WHERE, GROUP BY, ORDER BY |
| **चतुर्थी** | सम्प्रदानम् | GRANT TO (reserved; not yet parsed) |
| **पञ्चमी** | अपादानम् | FROM (source) |
| **षष्ठी** | सम्बन्धः | Property access |
| **सप्तमी** | अधिकरणम् | INSERT INTO |

## उदाहरणम्

**SSQL:**
```ssql
ग्राहकेभ्यः नाम आह्रियताम् ।
```

**विश्लेषणम्:**
- `ग्राहकेभ्यः` = ग्राहक + भ्यस् (पञ्चमी बहुवचन; बहुवचने झल्येत् 7.3.103 makes the stem's अ into ए)
  - "ग्राहकेभ्यः" → "FROM customers"
- `नाम` = प्रथमा एकवचन
  - "नाम" → "SELECT name"
- `आह्रियताम्` = आ + √हृ + यक् + ताम् (लोट् कर्मणि; before यक्, ऋ becomes रि by रिङ् शयग्लिङ्क्षु 7.4.28: हृ → ह्रि)
  - "आह्रियताम्" → "fetch" (passive imperative)

**SQL:**
```sql
SELECT name FROM customers;
```

## पञ्चमी विभक्तिः (FROM)

पञ्चमी **अपादानम्** (source/origin) सूचयति।

SQL भाषायाः FROM खण्डः पञ्चम्या सूच्यते।

| एकवचनम् | द्विवचनम् | बहुवचनम् |
|---------|----------|---------|
| आत् / आयाः | आभ्याम् | एभ्यः / आभ्यः |

**उदाहरणानि:**
- `पुस्तकात्` (from one book)
- `पुस्तकाभ्याम्` (from two books)
- `पुस्तकेभ्यः` (from many books)

## तृतीया विभक्तिः (BY/WITH)

तृतीया **करणम्** (instrument/means) सूचयति।

SQL भाषायाः WHERE, GROUP BY, ORDER BY इति खण्डाः तृतीयया सूच्यन्ते।

| प्रयोगः | उदाहरणम् | SQL |
|--------|---------|-----|
| नियमेन | नियमेन (by rule) | WHERE |
| समूहेन | समूहेन (by group) | GROUP BY |
| क्रमेण | क्रमेण (by order) | ORDER BY |
