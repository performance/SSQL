# SSQL Documentation

Welcome to the SSQL (Samskrutam SQL) documentation. 

**SSQL is a subset of Samskrutam (Sanskrit)** designed for database queries. Valid SSQL code is valid Sanskrit prose, with only a few additional graphemes (numerals, operators). It compiles to standard SQL dialects.
